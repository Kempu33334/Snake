# Snake

![image](https://github.com/user-attachments/assets/0f743bce-1147-448a-bc7b-24c3a868816e)

_A pygame program, just the classic snake game._

**Controls:**
- WASD or arrow keys to move.

**Objective:**
- Collect as many red squares (apples) as possible and grow your snake.

**Losing:**
- If you crash into the wall, or into yourself, the game ends.
